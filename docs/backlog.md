## Сравнение и визуальная приёмка при скрытой Figma

Статус: открыт. Добавлено 6 октября 2026 по запросу пользователя.

Сравнение с Figma и сохранение визуальной приёмки в Storybook должны работать независимо от видимости Figma: окно может быть свёрнуто, а вкладка файла — скрыта. Пользователь не должен держать Figma рядом со Storybook ради завершения операции.

Наблюдение: активное соединение сохраняется с `visible: false`, но повторное чтение вложенной иконки `I4391:92047;1900:44734` возвращает сетевой таймаут Figma через 10 секунд. После показа вкладки чтение проходит. Причину и устойчивое решение проверить отдельно; увеличение таймаута само по себе не доказывает исправление.

Критерии готовности:

- Сравнение проходит при свёрнутом окне, скрытой вкладке и активном Storybook; переключение фокуса во время операции не ломает её.
- Нажатие OK сохраняет «Принято» в тех же условиях после успешной проверки актуальности источника и реализации.
- Изменения Figma после предыдущего снимка обнаруживаются; старый снимок или кэш не выдаётся за актуальный.
- Отключённый плагин, недоступный источник и смена файла показывают понятную причину; приёмка не назначается автоматически.
- Проверки включают изменения источника, переподключение и повторное открытие панели Storybook.

## Figma fileKey в живом подключении

Статус: открыт. Добавлено 6 октября 2026 по запросу пользователя.

Научить установленный Figma-плагин передавать ключ текущего файла через `pairing.saved` → WebSocket `hello` → `list_connected_files` и `get_file_overview`.

В исходном коде передача уже добавлена, unit/integration проходят. В живом подключении SD Enterprice ключ пока отсутствует; нельзя считать задачу завершённой.

Проверить: версию установленного плагина и запущенного bridge, доступность `figma.fileKey` для текущего типа плагина и manifest. Недоступность private API не скрывать и не заменять именем файла или ID корня документа.

Критерии готовности:

- Живое подключение передаёт `0gdcm1xq6DvKUCR5RVw2wz` для подтверждённого файла SD Enterprice.
- Ключ сохраняется после переподключения, ID подключения меняется.
- Копия файла получает свой ключ; переименование сохраняет прежний.
- Старый плагин без ключа продолжает работать; операции с постоянной идентичностью показывают ограничение.
- Плагин ничего не записывает в готовые Figma-компоненты ради идентичности.
