# Однократное подключение Storybook

Код доступа разрешает обращения к локальному API сравнения и визуальной приёмки. Он отделён от кода подключения Figma: подключение плагина не даёт браузеру право сохранять приёмку.

Bridge создаёт постоянный случайный код для каждого проекта Storybook. На Windows файл хранится в `%LOCALAPPDATA%/figma-codex-mcp-bridge/storybook-access/<hash-пути-проекта>.token`; на остальных платформах — в `~/.config/figma-codex-mcp-bridge/storybook-access/`. Он находится вне проекта, Git и transfer. Повреждённый файл останавливает запуск sync API, а не незаметно меняет код. Перезапуск bridge сохраняет код.

В панели «Figma: изменения» нужно ввести код один раз. После успешной проверки панель сохраняет его в localStorage браузера. Старое значение из sessionStorage переносится туда только после проверки. Панель сама подключается при открытии, обновлении страницы и возвращении bridge после временного обрыва; неверный код не вызывает бесконечных повторов. Форма скрывается в «Настройках подключения».

Сохранение действует для конкретного браузера и адреса Storybook: `localhost` и `127.0.0.1` имеют раздельные хранилища. Очистка данных, приватное окно, другой браузер или адрес требуют первого подключения заново. Если браузер запрещает localStorage, панель сообщает, что подключение действует лишь в текущей вкладке.

«Забыть подключение в этом браузере» удаляет сохранённый код из браузера, но не отменяет код bridge. Для сброса серверного кода: остановить bridge, удалить соответствующий `.token`, запустить bridge и получить новый код через `get_storybook_sync_code`. После этого ранее сохранённые подключения потребуют нового кода.

Автоподключение только загружает статус. Сравнение и визуальная приёмка остаются явными действиями пользователя.

Проверки: постоянство кода после повторного запуска, одновременное создание, изоляция проектов, сохранение существующего кода и отказ при повреждении; автоподключение, миграция sessionStorage, сохранение только после авторизации, забывание, восстановление после обрыва и остановка повторов при 401.
