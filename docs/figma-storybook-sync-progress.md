# Figma → Storybook: состояние реализации

6 октября 2026. Реализована первая версия для Button; расширение на остальные компоненты остаётся в плане.

- Установленный bridge активен. Постоянный отдельный код Storybook хранится вне проекта; браузер сохраняет проверенный код и автоматически подключается после обновления, открытия новой вкладки и повторного запуска. Подробности — `storybook-access.md`.
- Начальная база Button проверена по 96 токенам и SVG-источникам, затем принята пользователем. Последующие намеренные изменения в Figma снова перевели Button в «Требуется перенос». Новый зелёный фон и отступы в код Button ещё не переносились.
- Панель показывает нумерованные пункты, цвета/стили и конкретные изменения геометрии. Превью «Было / Стало» строятся из сохранённых снимков `implemented` и `observed`, с размерами, отступами и выделением изменённых областей. Защищённый `/sync/previews` не требует нового чтения редактора и не назначает приёмку.
- Последние проверки: 127 тестов bridge, 18 тестов панели, typecheck bridge и менеджера, lint изменённых файлов, сборки bridge/transfer и Storybook. Для начальной базы Button отдельно прошли 14 unit-тестов и 9 браузерных проверок.
- Открыты: fileKey живого плагина, работа сравнения/приёмки при скрытой Figma, контрактные исключения, граф зависимостей и остальные компоненты. Требования записаны в `backlog.md`.
- Конфигурация, локальное состояние, коды и браузерная диагностика исключены из Git и transfer. Визуальную приёмку назначает пользователь; готовые компоненты Figma агентом не изменялись.

- Атомарное локальное состояние `.figma-sync/state.json`: наблюдение, перенос, приёмка. Экспорт не снимает маркер. Обновившиеся Figma/код или устаревшая ревизия блокируют OK.

- Локальная конфигурация `figma-sync.local.json` указывает текущий Storybook-проект; конфигурация и временное состояние исключены из Git и transfer.

## Следующий обязательный шаг

На порту 3846 сейчас работает прежний процесс bridge. Он не загрузил новый HTTP API; порт 3847 не слушается. Живое сквозное сравнение новой версией пока не подтверждено.

1. Перезапустить подключение локального bridge в Codex, чтобы загрузилась новая `dist/bridge/index.js` из этого проекта. Плагин Figma должен автоматически переподключиться с сохранённым pairing code.
2. Получить новый `get_storybook_sync_code`; ввести его в панель Storybook. Этот код отдельный и обновляется после перезапуска bridge.
3. Подтвердить, что текущий открытый SD Enterprice соответствует сохранённой ссылке. Пока fileKey недоступен, такое подтверждение действует только на текущее подключение.
4. Запустить «Сравнить с Figma» для Button. Исторический экспорт остаётся кандидатом, а не автоматически принятой базой. Уточнить найденные различия и ограничения.
5. После подтверждённого переноса точного снимка в код зарегистрировать реализацию через MCP; только пользовательский OK назначает визуальную приёмку.
