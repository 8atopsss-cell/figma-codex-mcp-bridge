# Figma Codex MCP Bridge

Личный плагин Figma, которым управляет основной чат Codex через MCP. Цель: читать открытый файл, создавать экраны и менять редактируемые слои по командам из чата Codex. Чат и вход остаются в Codex; внутри Figma — только плагин-мост.

Сейчас репозиторий содержит [план реализации](IMPLEMENTATION_PLAN_V2.md). Код плагина и локального MCP-моста ещё не создан.
